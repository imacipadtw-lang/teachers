# 10/28 雙語研習 飲料訂單

老師用手機點飲料（美式咖啡／拿鐵咖啡／英式奶茶／水果茶，各選冷或熱），承辦人在「訂單統整」分頁看總數與名單，一鍵複製文字給飲料店或貼 LINE。

- 表單網頁：`index.html`（放在 GitHub Pages）
- 訂單資料：Google 試算表「1028雙語研習 飲料訂單」
- 後端：`Code.gs`（Google Apps Script，綁在上面那張試算表）

## 設定步驟（只要做一次，約 5 分鐘）

1. 開啟試算表「1028雙語研習 飲料訂單」 → 上方選單 **擴充功能 → Apps Script**。
2. 把編輯器裡原本的內容刪掉，貼上 `Code.gs` 全部內容，按 **儲存**（磁片圖示）。
3. 右上角 **部署 → 新增部署作業** → 左邊齒輪選 **網頁應用程式**：
   - 執行身分：**我**
   - 誰可以存取：**所有人**（一定要選這個，老師才不用登入）
   - 按 **部署**，第一次會要求授權：選你的 Google 帳號 → 進階 → 前往（不安全）→ 允許。
4. 複製出現的 **網頁應用程式網址**（`https://script.google.com/macros/s/.../exec`）。
5. 打開 `index.html`，找到 `const SCRIPT_URL = "";`，把網址貼進引號裡，存檔後推上 GitHub。

之後只要把 GitHub Pages 的網址（加 `drinks/`）貼到 LINE 群組即可。承辦人看結果：同一個網址後面加 `#list`，或點「訂單統整」分頁。

## 注意

- 同一個姓名再送一次會覆蓋舊的訂單（方便老師改單）。
- 如果之後修改 `Code.gs`，要重新 **部署 → 管理部署作業 → 編輯 → 版本：新版本 → 部署**，網址不會變。
- 下一場研習要再用，複製 `index.html` 改日期與講師，再接一張新的試算表即可。
