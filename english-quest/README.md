# 土城國小 運動會英語日 六關闖關（english-quest）

網址：https://imacipadtw-lang.github.io/teachers/english-quest/

- 六間教室各開一關：`station.html?gate=1`～`6`（也可用 `index.html#gate-1`～`#gate-6`）。
- 終點解碼關＋家長看板：`control.html`（`#final`）；大廳開場：`opening.html`（`#opening`）。
- 老師工具：`guide.html` 活動手冊、`teacher-cards.html` 關主一頁卡、`cards.html` 護照 QR 卡、`phone.html` 老師手機登記。
- 學生名單只存在各台電腦的瀏覽器（localStorage），不在本倉庫。
