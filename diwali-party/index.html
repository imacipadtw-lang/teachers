Ankita 主教前 20 分鐘，中師主教後 20 分鐘。大螢幕只開「上課簡報」一個網頁，學生的 iPad 開 Lunch Box Lab。全程不用紙本。

大螢幕上課簡報中師的後 20 分鐘。一直按「下一步」就好，Spin、Impostor、Speed Round 會直接在簡報裡打開；計時器和課堂時間都在畫面上。打開簡報 → 手機或平板上課腳本每一段按幾下、我說哪一句、Ankita 做什麼。含課前檢查表。看腳本 → 觀課與議課教案素養導向設計、理論基礎、課綱對應、評量與觀課焦點。看教案 → 學生 iPadLunch Box LabCatch、Party Menu 和延伸練習。老師的「使用說明」與「學習證據」也在裡面。打開程式 →

上課當天只做三件事

  1. 大螢幕用 Chrome 或 Edge 打開「上課簡報」，按 F 全螢幕，停在第 1 頁。
  2. 六台 iPad 掃下面的 QR code 打開 Lunch Box Lab，各自進 Catch 聽一個字，確認有聲音。
  3. Ankita 講完交棒句，開始按「下一步」。腳本放在手邊的手機上。
