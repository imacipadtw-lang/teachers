# Popular games -> English-vocabulary mini-games (Taiwan, elementary): sourced rankings

Snapshot date: **2026-11-09** (GitHub stars pulled live at ~16:00 UTC the same day).
Purpose: choose ~25 well-known game mechanics to re-skin as English vocabulary / spelling / listening / sentence mini-games for a 700-word elementary word list (ages 7-12).

## How to read this file (method and limits)

- **Confidence codes** used in every table:
  - **P** = primary/official (company IR or SEC filing, the developer's own site or press release, the platform's own help centre, SteamDB for Steam concurrency).
  - **S** = reputable secondary source quoting a primary figure (trade press quoting an earnings release, Guinness, AP).
  - **E** = third-party estimate (Sensor Tower, AppMagic, trackers, blogs). Use these for ordering, not as hard facts.
- **Access limits this session:** web pages could not be opened directly (the page fetcher was blocked by network policy), so figures were taken from search-engine extracts of the cited pages and cross-checked across 2+ results where possible. Before publishing any single number, open its URL and confirm. Nothing in this file is invented; where no figure was found, the cell says so.
- **There is no single metric that covers all games.** Mobile games publish downloads/revenue, PC games have Steam concurrency, platforms publish DAU/MAU, older games only have lifetime sales. Table A therefore groups games by metric and ranks within each group, then gives one clearly-labelled editorial ranking that combines them.
- **GitHub:** stars come from the GitHub REST search API (`gh api search/repositories`), because the per-repo endpoint was blocked in this session. Topic searches (game, games, html5-game, browser-game, javascript-game, game-2d, puzzle-game, 2048, tetris, wordle, typing-game, educational-game, snake-game, flappy-bird, minesweeper) plus plain queries (`game in:name,description stars:>5000`, etc.) plus targeted `repo:` lookups for famous untagged repos.

## Notable source conflicts and data caveats

1. **Roblox Q3 2026:** DAU 138M is consistent across summaries, but "hours engaged" appears as ~29B in one summary and "nearly 34B" in another. Several sites still show 151.5M DAU, which is the **Q3 2025** figure. Read the 2026-10-29 shareholder letter on ir.roblox.com before quoting.
2. **"Best-selling game ever":** Tetris (>520M units, all versions and platforms, Tetris Co.) vs Minecraft (350M, single game, Guinness). Both are defensible; state the counting rule.
3. **Minecraft, Fortnite, Candy Crush, LoL, PUBG Mobile have no current official MAU.** Tracker estimates conflict (Fortnite MAU quoted from ~110M to 250M+; Candy Crush 81.5M vs 170-176M). Only official numbers were ranked.
4. **Candy Crush $20B:** King said "franchise"; Reuters wrote "Candy Crush Saga". Store-only estimates are far lower (AppMagic ~$7.7B IAP), because King's figure includes all revenue.
5. **CS2 all-time peak:** 1,862,531 (2025-04-12, SteamDB via press) vs a stale 1,824,989 still shown on some trackers. **Dota 2:** 1,295,114 vs 1,291,328.
6. **2025 mobile charts (AppMagic):** Block Blast 356.2M vs 368.3M downloads in two outlets. Top-grossing: PocketGamer.biz has Royal Match ~$1.9B, MobileGamer.biz $1.37B; Udonis puts Monopoly GO #1 ($2.21B) while AppMagic-based lists put Honor of Kings #1. Different trackers and webshop/off-store revenue explain most of the gap.
7. **Kahoot answer-streak bonus:** older Kahoot engineering posts describe +100 to +500 streak bonuses; the current help article says streaks give no extra points in standard games. Treat streak bonus as a design idea, not a current Kahoot feature.
8. **Blooket / Baamboozle / Gimkit user counts** are not published officially; third-party figures conflict (Blooket 10M vs 15M+; Baamboozle 400k vs 500k+ teachers). Gimkit's last official figure is from 2018.
9. **Geometry Dash peak:** 103,840 vs 108,569 / 108,707 depending on tracker.
10. **PaGamO users:** ">3 million" (profile) vs "350,000 global users" (older University of Michigan article); different dates and definitions.
11. **Wordle:** 4.2B plays in 2025 (AP) vs 4.8B in 2023 (CBS); a counter site's ~1.18B/year is unreliable.
12. **Single-source figures to verify:** Mario Kart World 16.48M and Switch 2 26.35M (as of 2026-09-30, Gematsu); Free Fire >100M DAU Q2 2026 (Garena-partner site); Stumble Guys 700M downloads (one interview).
13. **EdTech Top 40 2026:** one result said a 2026 edition came out on 2026-06-29; a second search found nothing. Only the 2025 edition is used.
14. **Old but still the latest:** Among Us 500M MAU (2020), LoL 180M (2021), Genshin $4B (2023), PvZ2 (2013), slither.io (2016), Fruit Ninja 1B (~2015). Use them as historical popularity, not current activity.
