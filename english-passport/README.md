# English Passport World Tour 英語護照環遊世界（english-passport）

網址：https://imacipadtw-lang.github.io/teachers/english-passport/

- 土城國小英語護照 700 個單字、25 關，每關一款遊戲，另有學習卡、護照蓋章考、班級對戰、錯題複習、單字圖鑑。
- 🎤 唸給老師聽：學生在關卡卡片逐字錄音，全部合成一個完整的 WAV 檔；老師在教師專區（預設密碼 0000，請先修改）反覆聽、下載，並給星星、評語、要再練的字、語音回饋，學生在首頁看到回饋。
- 學生名字、進度、錄音與回饋只存在各台裝置的瀏覽器，不在本倉庫，也不會上傳。
- 本資料夾是建置後的遊戲（由另一個開發專案的 `dist/package` 產生），請不要直接修改；教師使用說明見 `教師使用說明.md`。
