# 土城國小 課務查詢

教師自助查詢工具：查空堂、找代課、同班對調、跨班互換、三角調。
純前端單檔網頁，沒有後端、沒有資料庫、不需登入，公開給全校老師使用。

課表版本：**115學年度第1學期・2026.09.14 正式版**（15 位授課老師、6 個班級、178 個授課節次）

---

## 放上 GitHub Pages（約 3 分鐘）

1. 在 GitHub 按右上角 **＋ → New repository**，名稱例如 `tucheng-schedule`，選 **Public**，建立。
2. 進入新倉庫，點 **Add file → Upload files**，把 `index.html` 拖進去，按 **Commit changes**。
3. 點上方 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 **main / (root)**，按 **Save**。
4. 等一兩分鐘重新整理，頁面上方會出現網址：
   `https://<你的帳號>.github.io/tucheng-schedule/`
5. 把網址貼到學校 LINE 群組。老師用手機開啟後，可以「加入主畫面」當成 App。

檔案就只有 `index.html` 一個，含課表資料與校徽，不依賴外部服務（網路字型載入失敗時會自動改用系統字型）。

## 三個分頁

| 分頁 | 做什麼 |
|---|---|
| 找代課・調課 | 選「我是誰 → 哪一天 → 哪一節」，列出四種處理方式 |
| 空堂一覽 | 一眼看出每節有幾位老師沒課，點格子看名單與各班課程 |
| 課表 | 班級課表、老師個人課表，可直接列印 |

## 四種方案怎麼算出來的

1. **找人代課**：該節在全校六個班都沒有課的老師。會標示本班導師、教過這個班的老師，以及每個人當天與本週的節數，避免找到整天滿堂的人。
2. **同班兩節對調**：同一班的另一節課，必須同時成立「對方在你那一節空堂」與「你在對方那一節空堂」。
3. **跨班兩人互換**：對方來上你這一節，你去上對方在別班的一節，雙方互相都有空。
4. **三角調（三人接力）**：前面都不成立時，三個人輪一圈，每人只動一節。

每個方案都有「複製說明」按鈕，複製後可直接貼進調課單或 LINE。

## 協同、合班、分組課的處理

- **協同課**（中年級體育＝三甲＋四甲，由兩位老師一起上）：只要其中一位請假，這一節仍需處理。系統會提示搭檔仍在場，同時照常列出代課與調課方案；整節對調時會檢查兩位老師在新節次都有空。
- **低年級合班**（一甲＋二甲音樂、視覺藝術）：兩班一起上，對調時要求兩班在新節次都是同一堂課、同一位老師。
- **分組課**（本土語分閩南語／客語／布農語）：兩組同時進行，不列整節對調建議，請改用代課。

兩班一起上的課，畫面一律以學段稱呼：低年級（一甲＋二甲）、中年級（三甲＋四甲）、高年級（五甲＋六甲）。

## 課表更新時

課表異動後，請教務組重新產生 `index.html`：把新的全校課表 Excel 和 `build.py`、`app.html` 放在同一層，執行

```bash
python3 build.py 115-2全校課表.xlsx
```

產生的 `index.html` 重新上傳到 GitHub 即可。`build.py` 會在產生前印出每位老師與每班的節數，請與課表上的數字核對後再上傳。

Excel 格式需與目前相同：第 3 列為班級標題（含導師姓名），A 欄為星期、C 欄為節次、D～I 欄為六個班級，儲存格格式如 `國語(劉佳雯)`、`三甲中年級體育\n(詹可德+廖恒慈協同)`、`五甲本土語(李致德)／客家語海陸腔(陳怡璇)`。

## 資料與隱私

頁面只含課表（班級、節次、科目、授課老師），不含請假、代課費或任何個人資料，可公開張貼。
