# 作業抽查紀錄（土城國小）

全校作業抽查的線上登記表：每位學生、每本習作一個開關，考卷（家長已簽名）繳回以印章登記；教務組看全校，各班導師在登入頁選自己的班級就能用，只看得到自己的班，所有人開啟網頁就是最新情形。

網址：`https://imacipadtw-lang.github.io/teachers/homework-check/`

| 部分 | 位置 | 功能 |
|---|---|---|
| 網站（前端） | 本資料夾 `index.html`、`config.js`、`assets/`，GitHub Pages 發布 | 班級登記、掃描登記、全校總覽、報表、Excel、家長通知單、標籤列印、設定 |
| 資料表 | Google 試算表「作業抽查_資料表」（第一次使用自動建立） | 所有資料的正本（`data` 分頁）；「異動紀錄」分頁；可另產生易讀的「總表」分頁 |
| 後端 | Apps Script 專案「作業抽查_後端程式」：`apps-script/Code.gs` | 身分驗證（教務組登入憑證、導師裝置綁定）、讀寫資料、異動紀錄 |

### 功能一覽
- **登記**：每位學生每本習作一個開關、考卷（家長簽名繳回）紅色登記；依項目「收件」逐號點；條碼／QR 掃描登記；斷線時先存在本機、恢復後自動補送。
- **不用繳**：這一次、這一班不用繳的習作或考卷，在表頭按「不用繳」即可移除，隨時可恢復（見下方「不用繳的習作或考卷」）。
- **找學生**：搜尋座號或姓名、「只看未繳齊」。
- **全校總覽**：完成率、已交／應交、全班繳齊、導師已登入、截止倒數；各班完成率長條圖；各班各項目人數。
- **報表（給主任、校長）**：全校摘要、未繳交與備註、各班明細、歷次抽查完成率趨勢；可列印、下載專業排版的 **Excel 報表**或 CSV。
- **家長通知單**：每位缺交學生一張「作業繳交提醒」，A4 每頁 3 或 4 張。
- **管理**：抽查次別（可結案）、檢查項目與條碼代碼、班級名單與科任老師、導師登入裝置（解除、全部重新登入、暫停新登入）、教務組密碼、下載備份、寫入試算表總表。
- **查核**：試算表「異動紀錄」記下每一次登記、取消、備註與設定變更。
- **品質**：手機、平板、電腦皆可用；深色模式；無障礙（WCAG 2.1 AA 檢查 0 項問題）；自動測試 `tests/run.sh`。

> **更新後端**：`apps-script/Code.gs` 有更新時，請整份貼到 Apps Script，存檔後「部署 → 管理部署作業 → 編輯 → 版本：新版本 → 部署」。網站在後端更新前也能照常使用，但登入憑證、異動紀錄、不用繳、暫停新登入、歷次趨勢等功能要更新後才會生效。

**本倉庫公開，請勿把密碼、導師姓名、學生名單寫進任何檔案**；這些只存在試算表與 Apps Script「指令碼屬性」。

## 一、安裝（只做一次，約 10 分鐘）

### 1. 建立後端（Apps Script）
1. 到 https://script.google.com → **新專案**。
2. 把編輯器內原本的內容全部刪掉，貼上本倉庫 `apps-script/Code.gs` 的全部內容，按 **儲存**；左上角可把專案改名為「作業抽查_後端程式」。
3. 不需要另外建試算表：第一次使用時程式會自動在雲端硬碟建立「作業抽查_資料表」。

### 2. 部署成網頁應用程式
1. 右上角 **部署 → 新增部署作業** → 左邊齒輪選 **網頁應用程式**。
2. 執行身分：**我**；誰可以存取：**所有人**（一定要選這個，導師才不用 Google 登入）。
3. 按 **部署** → **授予存取權** → 選自己的帳號 → 允許（這是自己寫的程式，可放心）。
4. 複製出現的 **網頁應用程式網址**（`https://script.google.com/macros/s/…/exec`）。

### 3. 把網址填進網站
1. 在 GitHub 開啟 `homework-check/config.js` → 鉛筆（編輯）。
2. 把網址貼進 `apiUrl: ""` 的引號內，按 **Commit changes**。一兩分鐘後網站生效。

> 還沒填網址時，網站會顯示「尚未連接資料表」，可以先在那裡貼上網址試用（只記在那台裝置）。

### 4. 第一次設定（在網站上）
1. 開啟網站，畫面會顯示「第一次使用」：設定一組 **教務組密碼**（至少 6 個字）。設完會自動登入。
2. **設定 → 班級與學生名單**：填導師姓名、貼上每班名單（每行「座號 姓名」，可直接從 Excel 兩欄貼上），勾選本班有習作的科目並填科任老師。按「儲存項目與班級設定」。
3. **設定 → 抽查次別**：預設已有本學期第 1 次，填繳交截止日後「儲存」。
4. 把網址貼到學校 LINE 群組即可，導師自己選班級登入。

## 二、日常使用

### 導師
- 開啟網址，在下拉選單選自己的班級（會顯示導師姓名）按「登入」。第一台登入的手機／電腦會被記住，之後直接開網頁即可，不需密碼，只看得到自己的班。建議「加入主畫面」當 App 用。
- 一個班只能有一台裝置登入；選單裡已登入的班級會顯示「（已登入）」而不能再選。
- 收到習作時：點項目卡片「快速收件」，依本子點座號；或在名單上直接撥開關。
- 找學生：表格上方的搜尋框輸入座號（例如 12）或姓名；按「只看未繳齊」只列出還有缺交的學生。列印時一律印全班。
- 家長簽名的考卷繳回：點「簽」印章（紅色＝已繳回）。
- 「未交名單」一鍵產生文字，可複製貼到 LINE 提醒家長。
- 換手機、或不小心用別人的手機登入：請教務組到「設定 → 導師登入裝置」按「解除」，再用新裝置登入。

### 教務組
- **班級檢核**：切換各班登記，和導師看到的一樣。
- **全校總覽**：各班各項目進度、完成率、最後登記時間；可產生全校未交名單、匯出 CSV、列印。
- **設定 → 抽查次別**：每次抽查建立一筆；抽查結束勾「結案」，導師就不能再更動（教務組仍可更正）。
- **設定 → 系統**：「將本次抽查寫入試算表總表」會在試算表新增一個易讀的分頁，方便留檔或列印；修改教務組密碼。

### 設定頁
- 「抽查次別」的項目勾選、「班級」的本班項目都是「科目 × 習作／考卷」的表格；「檢查項目」是一張表，習作一組、考卷一組，可改名稱、簡稱、條碼代碼、適用年級。
- 「班級與學生名單」每班收合成一列（班名、年級、導師、人數），點開才編輯；各科科任老師在該班的「本班項目與科任老師」填。

### 不用繳的習作或考卷
| 情況 | 怎麼做 |
|---|---|
| 這一次、這一班不用繳（例如老師這次沒出社會習作） | 「班級檢核」在該欄表頭按「**不用繳**」。隨時可按「恢復」，已登記的紀錄不會不見。導師畫面會顯示「本次不用繳：○○」。 |
| 這一次全校都不查 | 「設定 → 抽查次別 → 本次項目」取消勾選。 |
| 這一班整學期都沒有這項 | 「設定 → 班級 → 本班項目」取消勾選。 |
| 全校整學期都不查 | 「設定 → 檢查項目」按「移除」。 |

### 考卷（家長簽名）
考卷依科目分欄，和習作分成兩組顯示（表頭「習作」｜「考卷（家長簽名繳回）」）。預設依期中評量科目：一、二年級 國語／數學／生活；三到六年級 國語／數學／英語／社會／自然。要調整到「設定 → 檢查項目」（類型選「考卷」）。標籤頁勾「也印考卷標籤」可印各科考卷的標籤。

### 備註與報表（教務組）
- 班級檢核表最右邊有「備註」欄，每位學生一則（例如「未訂正」「補交」「家長未簽名」），表格上方另有「本班備註」。打字後自動儲存；導師看不到備註。
- 「報表」分頁是給主任、校長看的版本：全校摘要（各班各項目已交人數、完成率、班級備註）、未繳交與備註名單、各班明細（✓／✗＋備註）。可直接列印或匯出 CSV（含備註）。「寫入試算表總表」也會帶備註。

### 家長通知單
班級檢核按「**家長通知單**」（教務組在「報表」頁也有，可選全校）。每位還有缺交的學生印一張「作業繳交提醒」：班級座號姓名、還沒交的習作與考卷（考卷註明請家長簽名後繳回，附勾選方格）、繳交截止日、導師與家長簽名欄。A4 每頁 3 張或 4 張，有裁切線。「給家長的話」可以修改，`{次別}`、`{截止}` 會自動換成這次的名稱與截止日；本次不用繳的項目不會列出。導師只能印自己班。

### Excel 報表（給主任、校長）
「報表」頁按「**下載 Excel 報表**」（全校總覽也有）。一個檔案包含：
- **全校摘要**：全校完成率、已交／應交、全班繳齊班數；各班各項目已交人數（習作藍、考卷紅分組）、完成率（100% 綠底）、班級備註、全校合計。A4 橫向。
- **未繳交與備註**：每位有缺交或備註的學生一列，缺交數、「習作：國語、數學｜考卷：數學（家長簽名）」、備註。
- **各班明細**：一班一張，✓／✗、已交／應交、繳齊與否、備註。A4 直向。

表頭凍結、列印每頁重複表頭並附頁碼，可以直接列印或轉寄。CSV 仍保留，給要自行加工的人使用。

### 掃描登記（標籤機＋手機或掃描器）
1. 教務組到 **設定 → 系統 → 列印習作標籤**：選班級、「一本習作（含科目）」、QR Code 或 Code 128 條碼、標籤尺寸，按「列印」。A4 貼紙或標籤機（Brother QL 等）都可以；列印時選「實際大小」。
2. 標籤貼在每本習作封面，上面印「學號＋科目」（例如 `10101國語習作`、`10101國語考卷`）、姓名、班級座號。條碼編號＝年級 1 碼＋班序 2 碼＋座號 2 碼（`10101`＝一年甲班 1 號）；含科目再加 2 碼科目代碼（習作：01 國語、02 數學、03 英語、04 生活、05 社會、06 自然、07 健康；考卷：11 國語、12 數學、13 英語、14 生活、15 社會、16 自然；`1010102`＝一甲 1 號數學習作，`1010112`＝一甲 1 號數學考卷）。班序在「設定 → 班級」、科目代碼在「設定 → 檢查項目」可改。編號印在標籤上，掃不到時可手動輸入。舊格式 `HW.g3.5.math` 仍可讀。
3. 收作業時按班級頁的 **掃描登記**：
   - 手機／平板：按「開啟相機掃描」，對準 QR Code 即登記，會有提示音與震動。
   - 條碼掃描器（USB 或藍牙，鍵盤模式）：直接掃，輸入會自動進到畫面上的輸入框；掃描器要設定「掃完送出 Enter」。
   - 掃到同一本第二次只會提示「已經登記過」，不會取消。導師掃到別班的標籤會被擋下；教務組掃到別班會自動切換到該班。
4. 「一位學生（不含科目）」的標籤：掃描前先在上方選要登記的科目，適合整疊同一科收。
5. 勾選「QR 內含網址」印出的 QR，用手機內建相機掃也能直接開網頁登記（已登入的裝置才會生效）。

**NIIMBOT（精臣）等標籤機 App**：標籤頁按「下載 NIIMBOT 用 Excel」，得到單一工作表、第一列為標題、全部文字格式的 .xlsx（欄位：班級、座號、姓名、科目、班級座號、QR條碼內容；每列一張標籤）。在 App 新增標籤 → 匯入 Excel（資料來源）→ 文字框綁定「姓名」「班級座號」「科目」，QR／條碼元件綁定「QR條碼內容」→ 整批列印。名單變動後重新下載即可。

相機掃描：Android Chrome 可讀 QR 與一維條碼；iPhone Safari 只讀 QR。掃描用的元件放在 `assets/vendor/`（qrcodejs、JsBarcode、jsQR，MIT 授權）。

### 權限
| 身分 | 看 | 改 |
|---|---|---|
| 教務組（密碼） | 全校 | 全部，含結案後更正、設定 |
| 導師（綁定裝置） | 自己的班 | 自己班的登記；結案後只能看 |
| 其他人 | 無 | 無 |

一個班級只能有一台裝置登入；教務組在「設定 → 導師登入裝置」按「解除」後，原裝置登出、該班可重新登入。

**暫停新的導師登入（建議）**：全部導師都登入後，到「設定 → 導師登入裝置」勾選「暫停新的導師登入」。這樣學生或其他人就算知道網址，也無法在登入頁搶先選班級；已登入的導師照常使用。

**讓導師重新登入**：
- 單一班級（導師換手機、登錯）：在該班按「解除」。即使正在「暫停新的導師登入」，這一班也可以馬上重新登入一次，不用取消勾選。
- 全部重來（新學年、換導師）：按「全部班級解除，讓導師重新登入」（要按兩次確認）。所有導師裝置登出、自動取消暫停；登記紀錄不受影響。

## 三、常見問題

- **網頁顯示「資料表回傳的不是資料」**：部署時「誰可以存取」沒有選「所有人」，或網址不是 `/exec` 結尾。重新部署一次並更新 `config.js`。
- **115.11.8 版 `Code.gs` 更新**（讀取改用 POST、密碼猜測防護）：請貼上新版後「部署 → 管理部署作業 → 編輯 → 新版本 → 部署」。網站在後端還沒更新前也能照常使用（自動改用舊的讀取方式）。
- **修改了 `Code.gs`**：必須 **部署 → 管理部署作業 → 編輯 → 版本：新版本 → 部署**，存檔不等於部署；網址不會變。
- **忘記教務組密碼**：Apps Script 編輯器執行 `showKey`（顯示）或 `resetKey`（重設），結果在「執行紀錄」。
- **教務組登入的安全性**：登入後瀏覽器只存一組「登入憑證」（180 天有效），不存密碼。按「登出」憑證立即作廢；修改密碼後其他裝置全部要重新登入。若懷疑有人用過教務組帳號，在 Apps Script 執行 `logoutAllAdmins` 可一次登出所有裝置。
- **顯示「密碼錯誤次數過多」**：15 分鐘內密碼錯 20 次，教務組登入會暫停 15 分鐘（防止有人用程式猜密碼；導師不受影響）。等 15 分鐘，或在 Apps Script 編輯器執行 `unlockAdmin` 立即解除。
- **畫面一直停在「載入班級中…」或「登入中…」**：Google 偶爾回應很慢。網站每次最多等 20 秒、自動重試 3 次，之後會顯示「Google 沒有回應」並在登入頁出現「重新載入班級」按鈕；按一下即可，不必重新整理。等待時間可在 `config.js` 加 `timeoutMs`（毫秒）調整。
- **網路斷線時登記會不會不見**：不會。登記先存在這台裝置，畫面右上會顯示「N 筆待送出」，網路恢復後自動補送；就算中途關掉網頁，下次用同一台裝置開啟也會補送。請不要在還有「待送出」時清除瀏覽器資料。
- **深色模式**：預設跟著手機／電腦的系統設定；頁尾「外觀」可固定為淺色或深色。列印一律是白底。
- **資料表在哪**：網站「設定 → 系統」有「開啟試算表」連結；也可在雲端硬碟搜尋「作業抽查_資料表」。
- **多人同時登記**：以每一格為單位合併，不會互相覆蓋；畫面每 45 秒自動更新，也可按同步旁的重新整理。
- **新學年**：到「設定」更新名單、導師與科任，建立新的抽查次別即可；舊次別與紀錄都保留。
- **異動紀錄（查核用）**：試算表會自動多一個「異動紀錄」分頁，記錄每一次登記／取消（誰、哪一班、座號姓名、項目、時間）、備註、設定變更、裝置綁定與解除、教務組登入。家長或導師對繳交情形有疑問時可查這裡。請勿刪改。
- **備份**：「設定 → 系統 → 下載備份（JSON）」會把所有抽查次別的登記、備註、不用繳、名單與設定存成一個檔案，建議每學期末存一份在學校電腦或雲端硬碟（檔案含學生姓名，請妥善保管）。試算表本身也是正本，`data` 分頁請勿改動。
- **歷次趨勢**：「報表」最下面「四、歷次抽查完成率」顯示全校完成率折線，以及各班每一次的完成率與變化（需新版後端）。

## 四、檔案說明

- `index.html`：網頁骨架。
- `config.js`：唯一需要修改的設定（資料表網址、校名）。
- `assets/style.css`、`assets/app.js`：外觀與程式。
- `apps-script/Code.gs`：後端。資料以 key／JSON 存在 `data` 分頁：`config`（項目、班級、名單）、`rounds`（抽查次別）、`checks:<次別>:<班級>`（登記）、`auth`（各班已登入的裝置）。
